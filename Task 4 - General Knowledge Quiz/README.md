General Knowledge Quiz

📌 Project Overview

This project is a simple General Knowledge Quiz created using Python.
The quiz asks the user 3 general knowledge questions and calculates the final score based on the answers.

🚀 Features

- Asks 3 General Knowledge questions
- Takes answers from the user
- Handles extra spaces and different letter cases using ".strip().lower()"
- Displays whether the answer is correct or wrong
- Shows the correct answer for wrong responses
- Increases the score for every correct answer
- Displays the final score out of 3

🛠️ Technologies Used

- Python

▶️ How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in a terminal or code editor.
3. Run the following command:

python general_knowledge_quiz.py

4. Answer all three questions.
5. Your final score will be displayed.
